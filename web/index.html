GOBUSTER RECON

Directory brute-force · hidden path discovery · admin/login/backup exposure · status code mapping

python3 gobuster-recon.py -u https://target.com
→ Directory Board GitHub ↗
> WHAT IS GOBUSTER RECON

Directory brute-force discovers paths that aren't linked from any page — admin panels, backup files, configuration endpoints, API routes. gobuster-recon runs gobuster dir against a target, parses all found paths with their status codes and redirect chains, classifies dangerous exposures (admin, login, phpMyAdmin, .git, .env, backups), and emits structured JSON. HTTP fallback mode runs a built-in wordlist check via urllib when gobuster is not installed.

> WHY THIS SCRIPT

Raw gobuster output is per-line text — no caching, no classification, no history. gobuster-recon adds 24h SQLite caching, structured JSON with exposure flags (has_admin, has_git, has_env, has_backup), automatic wordlist resolution (tries Kali/Parrot paths, falls back to built-in list), and community submission.

> HOW IT WORKS
INPUT: --url https://target.com
↓
cache.db (24h TTL)
↓ (stale or --no-cache)
gobuster binary? YES → gobuster dir -w wordlist NO → HTTP fallback (urllib HEAD)
↓
parse paths · status codes · redirects · sizes classify: admin / login / phpmyadmin / .git / .env / backup
↓
JSON output + terminal summary
> USAGE
# basic scan
python3 gobuster-recon.py --url https://target.com

# custom wordlist
python3 gobuster-recon.py --url https://target.com --wordlist /path/to/list.txt

# gobuster mode (default) or HTTP fallback
python3 gobuster-recon.py --url https://target.com --mode gobuster
python3 gobuster-recon.py --url https://target.com --mode http

# add file extensions
python3 gobuster-recon.py --url https://target.com --extensions php,html,txt,bak

# thread count
python3 gobuster-recon.py --url https://target.com --threads 20

# save JSON output
python3 gobuster-recon.py --url https://target.com --output results.json

# bypass cache (force fresh scan)
python3 gobuster-recon.py --url https://target.com --no-cache

# scan and submit to Directory Board
python3 gobuster-recon.py --url https://target.com --submit

> HIGH-VALUE FINDS
  • .git/HEAD — Full source code disclosure. If this returns 200, the entire repo is downloadable: git clone https://target.com/.git
  • .env — Environment file. Contains DB passwords, API keys, app secrets in plaintext. Critical severity if exposed.
  • phpmyadmin — Database admin interface. Unauthenticated access (or default creds) = full DB dump. Frequent on misconfigured shared hosting.
  • *.bak / *.sql / *.zip — Backup files. Database dumps and source archives sitting in webroot — direct credential and schema exposure.
  • admin / dashboard — Admin panels. Login forms not exposed via sitemap = credential attack surface (brute-force, default creds, bypass).
  • xmlrpc.php — WordPress XML-RPC endpoint. system.multicall enables batched brute-force (thousands of password attempts per request). Also a pingback SSRF vector.
> WORDLIST RESOLUTION ORDER
  1. -w flag if given
  2. /usr/share/wordlists/dirb/common.txt (Kali default)
  3. /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt
  4. /usr/share/wordlists/seclists/Discovery/Web-Content/common.txt
  5. Built-in 60-entry wordlist (always works — no install required)
